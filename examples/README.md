# Discovery Pack Examples

This directory contains reference implementations of discovery artifacts generated by the Discovery Pack.

## 📂 [full-mode-fintech-service/](./full-mode-fintech-service/)
**"The Gold Standard"**

A complete, rigorous example simulating a high-performance Payment Ledger project ("LedgerCore").
- **Mode:** Full
- **Complexity:** High (PCI-DSS compliance, High Throughput)
- **Key Features:**
    - **03_option-space.md**: Shows complex trade-off analysis (Postgres vs TigerBeetle).
    - **04_assumptions.md**: Demonstrates prioritized risk extraction.
    - **05_validation-plan.md**: Shows quantitative success criteria (Passes Gate 2).
    - **07_speckit-handoff.md**: Ready for engineering handoff.

Use this example to understand how to document mission-critical systems.

## 📂 [lite-mode-sample/](./lite-mode-sample/) (Planned)

## How to use these examples

You can run the validation scripts against these directories to verify they pass governance checks:

```bash
# Validate the Fintech example
python3 ../skill/discovery-pack/scripts/validate.py full-mode-fintech-service/
```
